# tethiel (テティエル) - ゲーム詳細仕様書・設計ドキュメント

中央大学国際情報学部（iTL）公式キャラクター「イティエル」をモチーフにした逆テトリス型アクションパズルゲーム。  
企画書「逆テトリス型 回路つなぎパズル」準拠。

---

## 1. プロジェクト概要 & 背景コンセプト

### 1.1 背景ストーリー
サイバー攻撃の魔の手が迫る中央大学 市ヶ谷田町キャンパス。  
プレイヤーは、イティエルと共に「iTL防衛戦」に挑む。  
iTLを守るためには、ウイルスよりも先にイティエルをサーバーへと連れて行かなければいけない！  
ウイルスに追いつかれないように回路を繋ぎながら、イティエルを導こう！

### 1.2 ゲームコンセプト
- **「積んでつなげる」逆テトリス型アクションパズル**: 通常のテトリスと異なり、上からミノを落として積み重ね、最下部の「START」から最上部の「GOAL」へと回路を繋ぎ合わせる。
- **イティエルの登頂アクション**: イティエルは最初START地点（画面最下部）に位置し、STARTから繋がったミノ（回路）を伝って上へ登っていく。
- **追いつかれる緊張感**: 時間経過に伴い、繋がった回路が最下部から順に黒くウイルス感染していく。最上部のミノ（イティエルがいる地点）にウイルスが追いついたらゲームオーバー。

### 2.2 フィールド & ルール仕様
- **フィールドグリッド**: 横12マス × 縦22マス。
- **STARTライン（最下部・行21）**: 中央（列5〜6）が回路の接続口。ゲーム開始時、イティエルはここに待機する。
- **GOALライン（最上部・行2）**:
  - 列0〜9: 通常GOAL
  - 列10〜11: **BONUS** ゴール（最高難度・高得点エリア）
- **回路接続判定**:
  - START地点から上下左右（4近傍）に隣接接続された設置ブロックを「通電回路」とする。
  - 回路の最前線（最も高い位置にあるブロック）を**白く光らせる**。
  - イティエルは回路を伝って、この白く光る最上部ミノの位置まで自動的に登る。
- **ウイルス感染進行（水平せりあがり型・2ミノ待機）**:
  - ゲーム開始時、プレイヤーが**2ミノを配置完了するまでウイルスは待機**し、2ミノ配置後に感染タイマーが動き出します。
  - 時間経過に伴い、最下行から順に**横一列（行単位）**で直線状のウイルス警戒ラインがせりあがってきます（揺れる波エフェクトのない直線のサイバー警戒線）。
  - せりあがったウイルス感染行にイティエルが呑まれると、ハートライフが減少（ハート0でゲームオーバー）。
  - 速度はファミリーや初心者でもじっくり考えられるようゆったりしたテンポに設計（STAGE 1: 4.5秒に1行）。
  - ※コード内には、従来の「回路パスを1マスずつ辿って黒色感染する」形式（`circuit_path`）も切り替え可能な形で保持されています。
- **横一列に関するルール**:
  - 横一列揃ってもライン消去や回復・一時停止等のプラス効果は一切ありません。
- **ゴール到達時の新規ミノ停止**:
  - イティミノ群（回路の最上部）がGOALライン（行2以下）の高さに到達した瞬間に、新規ミノの落下・出現処理を完全に停止し、登頂完了まで余計なミノが出現しません。
- **トゲ障害物トラップ**:
  - ステージ上にトゲトゲの危険な障害物が配置されている。
  - イティエルのいる通電回路（`isConnected`）に接続されていない孤立したミノがトゲ障害物に接触して接地した場合、トラップが発動して即座にミノが破壊され、ライフが1減少する（通電回路に繋がっている場合は安全に足場として利用可能）。
- **ボーナス星（★）**:
  - ステージ上の空中に浮遊配置されたアイテム。ミノを重ねて通過すると回収され、BONUSカウントが増加（スピーディな進行を損なわないようスコア配分は控えめに設計）。

### 2.3 操作方法
- 即置き（ハードドロップ）: `↑` または `Space`
- 左回転（反時計回り）: `Z`
- 右回転（時計回り）: `X` / `W`
- 左右移動: `←` / `→` または `A` / `D`
- ソフトドロップ: `↓` または `S`
- ホールド: `C` キー
- ボムスキル: `1` / `B` キー または画面上の「BOMB!」ボタン（操作ミノ周囲を爆破）
- 一時停止: `P` / `Escape`

## 3. 勝敗条件 & スコア換算

### クリア条件
- STARTから繋がった回路が最上部のGOALライン（行2以下）に到達し、イティエルがゴールする。
- 右端のBONUSエリアに到達した場合は「BONUS CLEAR」となり特大ボーナス点獲得。

### ゲームオーバー条件
- せりあがるウイルス（マグマ）にイティエルが呑まれる（ライフ喪失）。
- トゲ障害物等でライフが0になる。
- ミノの出現口が塞がれ、進行不能状態になる。

### スコア計算要素
- **クリア基本ボーナス**: 通常クリア 5,000点 / BONUSクリア 10,000点
- **時間マイナス補正**: 経過時間1秒ごとにマイナス減点補正（早くクリアするほど高得点）
- **ミノ数プラス評価**: ミノ数が少ないほど大幅ボーナス加算（基準20手に対し、少ない手数ほど大量加点）
- **星ボーナス**: 回収した星の数（1個200点）
- **残りライフ**: 残機ハート数（1個300点）
